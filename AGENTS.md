# Repo orientation for coding agents

This repo's guidance lives in [`CLAUDE.md`](CLAUDE.md). It is plain markdown and applies to any
agent, not just Claude Code. **Read it before editing anything here.**

The short version, because these three constraints are easy to violate by accident:

1. **The notebooks are the talk.** There are no slides, deliberately. Notebooks are committed
   *with their outputs*; if you change a code cell, re-execute the notebook so the figures and
   tables on GitHub stay in sync with the code.
2. **Results are reported honestly and must not be inflated.** The dengue model beats its
   benchmark by only about 2.5%. That modest number is the teaching point.
3. **No student data, ever.** The roster in notebook 02 is fabricated. Real names and addresses
   must not enter this public repo.

Also: **no em dashes** in English prose here.
